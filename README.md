# Data Cleaning and Preprocessing

This project is part of my Data Analyst Internship at Elevate Labs.

I used the Customer Personality Analysis dataset from Kaggle and cleaned it using Python and Pandas.

The work includes:
- Checking and handling missing values.
- Removing duplicate records.
- Standardizing column names and text.
- Converting date formats.
- Checking data types.
- Saving the cleaned dataset as a CSV file.

**Tools Used:** Python, Pandas and Google Colab.

The final cleaned dataset is ready for further analysis.
